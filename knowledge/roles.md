# Roles

## Known Test Roles

SauceDemo provides test users with different observable behaviors.

The exact credentials must not be stored in this file.

Credentials must be provided through environment variables or another secure mechanism.

## Initial Role

The initial PoC may use a standard authenticated test user.

The exact username and password should be supplied through the test environment configuration.

## Role Testing

When multiple test roles are available, the QA system should evaluate whether role-specific behavior differs.

Potential areas include:

* Authentication
* Authorization
* Available functionality
* Error handling
* Data visibility
* Workflow restrictions
