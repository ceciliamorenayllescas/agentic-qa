# Glossary

## SUT

System Under Test.

The application currently being tested.

## Test Area

A functional or risk area that should be investigated.

Examples:

* Authentication
* Validation
* Checkout
* Permissions

## Test Scenario

A high-level behavior or situation that should be tested.

## Test Case

A structured, reproducible set of actions and expected results.

## Exploratory Testing

Testing where learning, test design, and execution occur concurrently.

## Testing Charter

A concise mission defining the scope and objective of an exploratory testing session.

## Finding

An observation discovered during testing.

A finding is not necessarily a defect.

## Potential Defect

A finding for which the observed behavior may violate an expected requirement or product behavior, but which has not necessarily been confirmed.

## Evidence

Artifacts supporting a QA observation or result.

Examples:

* Screenshot
* Trace
* Video
* Execution output
