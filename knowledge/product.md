# Product Knowledge

## System Under Test

**Name:** SauceDemo

**URL:** https://www.saucedemo.com/

**Application type:** Web application

**Testing approach:** Black-box

## Known Areas

The application exposes functionality related to:

* User authentication
* Product listing
* Product details
* Shopping cart
* Checkout
* Order completion

These areas are initial observations and should be validated through browser exploration.

## QA Objective

The Agentic QA System should use the application as an external QA would.

The system should:

* Observe the application's behavior
* Identify available workflows
* Discover validations and business rules
* Generate test scenarios
* Execute exploratory testing
* Identify potential defects
* Generate reproducible Playwright tests

## Knowledge Boundary

Information not explicitly documented in this knowledge base should not be treated as an established business rule.

The agent should distinguish between:

* Known information
* Observed behavior
* Assumptions
* Unverified hypotheses
* Potential defects
